Stat Compass 0.1.0 — Retail 12.1.0
Copy this StatCompass directory into Interface/AddOns only after separate
installation approval. Open the Character equipment page to see the panel.
The panel matches CharacterFrame height and shows four current-stat rows.
Main numbers and bars show shares of your secondary-stat rating budget, not
combat-effect percentages. The marked band is the middle half of top players;
minimum, arithmetic mean and maximum are separate markers. Hover each value
for absolute rating details. The mean describes the sample, not a personal optimum.
Only verified share references enable graphics. Without a comparison all bar,
band, marker and glow graphics are hidden; a known own share is labelled separately.
If any of the four raw ratings is unreadable, all own shares are unknown.
Core supplies the axis and quartiles; the UI never calculates them.
Raid/Mythic+ and Default/Flat dark are selected in the panel. Reset restores
Raid, Default, and minimap defaults. German is automatic for deDE; English is the fallback.
Drag the minimap button to move it. Left-click opens equipment.
Right-click opens Options > AddOns > Stat Compass: choose Default/Flat dark,
show/hide the minimap button, or reset appearance (keeps Raid/Mythic+).
The angle and visibility persist across reloads. No extra feature window or libraries.

IMPORTANT: This package contains no licensed EU top 50 data. A readable own
budget share can be shown independently; reference values read Unknown.
