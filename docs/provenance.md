# Pinned research and release data status

Research snapshot: 2026-10-02. This repository contains original addon code; no Blizzard source, third-party datasets, or copied artwork is bundled.

## Retail API and layout

The live Retail product was 12.1.0 **client build `69933`**, with **interface `120100`** for the TOC. These are distinct fields: `GetBuildInfo()` return 2 is the client build string, return 4 the interface number. Both are checked before showing targets. Cross-check the client itself with `/dump GetBuildInfo()` before in-game acceptance. Build evidence: [Blizzard's patch version endpoint](http://us.patch.battle.net:1119/wow/versions), directly read in the [full source research](top50-eu-source-research.md), and the [Gethe live source commit](https://github.com/Gethe/wow-ui-source/commit/09b9db7948abc9b9648dedaab51eb0cf3ee67b31). The panel mirrors **Crit → Haste → Mastery → Versatility**. All displayed numbers are percentage points. [`GetMastery()`](https://warcraft.wiki.gg/wiki/API:GetMastery) reports mastery points, which are not necessarily the specialization's displayed mastery effect. The pinned Character-window source uses `GetMasteryEffect()` as its displayed percentage, so comparison data must be in mastery-effect percentage points. The source's versatility display includes both rating bonus and other versatility bonus. Crit uses the source's max(melee, ranged, minimum of spell schools 2 through 7) rule. If any required API value is secret or unavailable, the corresponding current value is unknown.

The addon attaches only when `CharacterFrame` and `PaperDollFrame` exist, including when Blizzard loads the character UI lazily. Both visibility hooks gate evaluation to the equipment page. It uses one-shot `C_Timer.After(0, ...)` only for visible event bursts, with generation invalidation on hide/reopen; there is no perpetual timer. The minimap launcher uses OnUpdate only during an active drag and clears it on drag stop or hide. See [controls API verification](controls-api.md).

## Third-party data audit

Inspected upstream: [VaughanT31/recommendedstats](https://github.com/VaughanT31/recommendedstats/tree/ea1ddf34af3ef1091f0680c4c6b52191bc62f151) at `ea1ddf34af3ef1091f0680c4c6b52191bc62f151`, including its [October 2 archive](https://github.com/VaughanT31/recommendedstats/blob/ea1ddf34af3ef1091f0680c4c6b52191bc62f151/Releases/RecommendedStats_V2.0.0-2026-10-02.zip). Its `LICENSE` is MIT, Copyright 2026 VaughanT31 (inspected SHA-256 `0452ad3399a4bb7b45294dac49b96176e558a27ce8cf9cb35086fea338b0da14`); full notice is in `StatCompass/NOTICE.txt`.

Its README says stat targets use top players from Warcraft Logs plus Battle.net API and **up to 20 players per spec**. Its `RecommendedStats/Data/Meta.lua` instead says `source = "raider.io + Battle.net API"`, `sampleSize = 20`, `gamePatch = "12.1.0"` (inspected SHA-256 `398e02b5dad7ac5620f6e93125b1b3a2d41e79f97cc2101d7d14ea5fd7a6464d`). Its generated `StatTargets.lua` uses percent-like decimal values, including mastery-effect values over 100 (inspected SHA-256 `1720dc7edc5ad953bda42badaaf2fc5db32f8fde74ff7e2f9d29c02fb024b286`). This inconsistency and the 20-player cohort prevent treating those values as the requested EU top 50. Upstream MIT covers its software, not automatically the underlying rankings or profile data.

[Historical EU top 50 source research](top50-eu-source-research.md) now has an erratum. Raider.IO's [official Swagger](https://raider.io/swagger.json) publishes GET /api/v1/client/character-rivals with scope=region and specId; its summary explicitly calls this a spec leaderboard window. The [local acquisition report](rio-acquisition.md) records a saved Arcane interval walk covering ranks 1–52. Four of ranks 1–50 are anonymous (15, 38, 40, 49), leaving 46 public identities. The windows do not constitute an atomic snapshot, and no all-spec result or redistribution approval is established. Warcraft Logs, Blizzard and Murlok limitations documented in the historical research remain separate considerations.

**Release blocker:** `StatCompass/Data.lua` deliberately contains no target values. The addon shows current stats and `Unknown` targets, and the panel states that licensed EU top 50 data is absent. This is not a release with meaningful recommendations. The schema and offline builder require source URL, raw-source SHA-256, exactly 50 selected and valid EU players per spec/context, observed and collection epochs, an expiry epoch, exact client build and interface, level, season, ranking metric, difficulty, partition, and explicit mastery-effect percent semantics. These checks only validate declared metadata. They cannot authenticate source truth, prove a complete ranking, confer reuse permission, or establish ongoing compliance for a permanently downloadable archive. The local Raider.IO rivals provider establishes bounded public rank acquisition only. Blizzard authentication/payload validation, full-spec coverage, redistribution review, retention/deletion handling, status checks, and distribution revocation remain before any real dataset ships.

The runtime and generator reject ratings entirely, including a suspicious value such as 4000 if labeled rating. Ratings cannot be compared directly with percentage points; their conversion depends on build, level, stat, and game rules. Crit percentage has a mathematical 100% probability ceiling. Other displayed percentages, especially mastery effect, are not assigned an invented universal maximum. Valid numeric percentages do not prove truthful observations. An observed mean and nearest-rank middle 50% band describe the selected cohort, not an optimum or a personal simulation result. The runtime also fails closed for unknown, future, or expired `GetServerTime()` values; a compiled expiry guard alone cannot enforce remote deletion of old ZIPs.
